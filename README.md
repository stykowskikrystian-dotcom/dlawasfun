# DlaWas.fun — Fotobudka 360

Nowoczesna strona promująca fotobudkę 360, oprawę muzyczną i dodatkowe atrakcje eventowe DlaWas.fun.

## Najważniejsze elementy

- pełnoekranowy hero z osobnymi filmami dla komputerów i telefonów,
- sekcja pokazująca działanie fotobudki 360,
- oferta wesel, eventów, nagłośnienia i animacji,
- dodatkowe atrakcje z fotografiami i animowanymi piktogramami,
- rozbudowany kontakt z telefonem, e-mailem i profilami społecznościowymi,
- responsywny układ oraz stale widoczna nawigacja.

## Uruchomienie lokalne

Wymagany jest Node.js `22.13.0` lub nowszy.

```bash
npm ci
npm run dev
```

Wersję produkcyjną można sprawdzić poleceniem:

```bash
npm run build
```

## Wdrożenie na Vercel

Projekt jest standardową aplikacją Next.js i nie wymaga niestandardowych ustawień buildu. Połącz to repozytorium z Vercel i pozostaw automatycznie wykryte ustawienia:

- Framework Preset: `Next.js`
- Build Command: `npm run build`
- Install Command: `npm ci`
- Output Directory: domyślna

Każdy push do głównej gałęzi utworzy wdrożenie produkcyjne, a pozostałe gałęzie otrzymają wdrożenia podglądowe.
